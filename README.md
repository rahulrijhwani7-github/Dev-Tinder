# Dev-Tinder
Developing Tinder like application for practicing Node and Mongo

Features:
1) create Account
2) Login
3) Update Account
4) Feed page
5) Send Connection Request (Swipe of orignal tinder)
6) See our matches
7) Received/Sent Request (Separate tabs for both)

Tech Planning:
1) Two microservices : FE & BE
2) FE : React
3) BE : NodeJS, MongoDB
4) Low level Design
